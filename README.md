# 🤖 Nova — AI Chatbot

**Nova** is a Java-based rule-driven AI chatbot developed as part of the **CodeAlpha Java Programming Internship – Task 3**.

It works as a **Full Stack Java Learning Assistant**, using NLP-style text processing and a predefined knowledge base to answer programming and development-related questions.

## ✨ Features

- 💬 Interactive console-based chatbot
- 🧠 NLP-style text processing
- 🎯 Keyword-based rule-driven responses
- ☕ Java & OOP concepts
- 🌐 HTML, CSS & JavaScript
- ⚙️ Spring & Spring Boot
- 🔗 REST API, JDBC, Hibernate & JPA
- 🗄️ SQL, MySQL & PostgreSQL
- 🔧 Git & GitHub
- 🔐 Authentication, Authorization, JWT & MVC
- 🕐 Date & time responses
- 👋 Greetings and general conversation
- ❓ Fallback responses for unknown questions

## 🛠️ Technologies Used

| Technology | Usage |

## 🧠 How It Works

**User Input** → **NLP Processing** → **Keyword Detection** → **Knowledge Base** → **Rule-Based Response**

Nova processes the user's input, identifies relevant keywords, searches the knowledge base, and generates an appropriate response.

## ▶️ How to Run

1. Open the project in VS Code or any Java IDE.

2. Compile the Java files:

   `javac *.java`

3. Run the chatbot:

   `java Main`
